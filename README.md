# ZebrappsSPA

A modern Single Page Application (SPA) boilerplate based on Vite.

## Features

- ⚡ **Fast Development**: Powered by Vite for lightning-fast HMR
- 🏗️ **Modern Build Tool**: Optimized build process with Vite
- 📦 **Ready to Use**: Minimal setup, maximum productivity
- 🎯 **SPA Architecture**: Optimized for single-page applications

## Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/zebrapps/ZebrappsSPA.git

# Navigate to the project directory
cd ZebrappsSPA

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Project Structure

```
ZebrappsSPA/
├── public/          # Static assets
├── src/             # Source code
├── index.html       # Entry HTML file
├── package.json     # Project dependencies
└── vite.config.js   # Vite configuration
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
